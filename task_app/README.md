# My Tasks

シンプルで美しいWebベースのタスク管理アプリケーション。Apple Design Systemに準拠した洗練されたUIで、直感的なタスク管理を実現します。

## 特徴

- **単一ファイル構成** - `mytasks.html` のみで動作。サーバー不要、依存関係なし
- **Apple風デザイン** - ミニマルで洗練されたUI、ガラスモーフィズム、滑らかなアニメーション
- **コンパクトUI** - タスクカードを最適化し、一覧性を向上
- **ダークモード対応** - システム設定に連動、手動切り替えも可能
- **完全オフライン** - localStorageでデータを永続化
- **レスポンシブ** - デスクトップ、タブレット、モバイルに対応
- **検索機能** - タスク名、メモ、サブタスクでリアルタイム検索
- **タッチ対応** - モバイルでのタッチドラッグ&ドロップ
- **アクセシブル** - ARIA属性、キーボード操作対応

## 機能

### タスク管理
- タスクの作成・編集・削除
- カテゴリとステータスによる分類
- 期限の設定（自由形式または日付ピッカー）
- メモの追加
- ドラッグ&ドロップによる並び替え

### サブタスク
- 各タスクにサブタスクを追加可能
- サブタスクごとに期限・メモを設定
- 個別の完了管理

### ビュー切り替え
| ビュー | 説明 |
|--------|------|
| Active | 進行中のタスク |
| Archived | 完了したタスク |
| Trash | 削除したタスク（復元可能） |

### 検索・フィルタリング
- **リアルタイム検索** - タスク名、メモ、サブタスクを横断検索
- カテゴリでフィルタ
- ステータスでフィルタ
- 組み合わせフィルタ

### カスタマイズ
- カテゴリの追加・編集・削除
- ステータスの追加・編集・削除（色付き）
- グローバルメモ欄

### データ管理
- JSONエクスポート/インポート
- 自動バックアップ（`_json/` ディレクトリ）

## 使い方

### 起動
`mytasks.html` をブラウザで直接開くだけで使用できます。

```bash
# macOS
open mytasks.html

# Windows
start mytasks.html

# Linux
xdg-open mytasks.html
```

### 基本操作

1. **タスク追加**: サイドバーの入力フォームに情報を入力し「追加」ボタン
2. **タスク編集**: タスクカード上で直接編集（タイトル、カテゴリ、ステータス等）
3. **タスク完了**: 「完了」ボタンでアーカイブに移動
4. **タスク削除**: 「削除」ボタンでゴミ箱に移動
5. **並び替え**: ドラッグハンドル（⋮⋮）をドラッグ

### キーボードショートカット
| キー | 動作 |
|------|------|
| `Enter` | タスク追加、モーダル確定 |
| `Escape` | モーダルを閉じる |

### タッチ操作（モバイル）
- **長押し（300ms）** + ドラッグ: タスクの並び替え
- ドラッグハンドル（⋮⋮）を長押しで開始

## 技術仕様

### 構成
- **HTML/CSS/JavaScript** のみ（外部依存なし）
- **localStorage** によるデータ永続化
- **Apple Design System** 準拠のスタイリング

### ブラウザ対応
- Chrome / Edge（推奨）
- Safari
- Firefox

### データ形式
```javascript
{
  tasks: [{
    id, name, status, category, deadline, memo,
    isArchived, isDeleted, createdAt, updatedAt,
    subtasks: [{ id, name, status, memo, deadline }]
  }],
  globalMemo: "",
  settings: {
    categories: [{ id, name }],
    statuses: [{ id, name, color }]
  }
}
```

## バックアップと復元

### エクスポート
1. サイドバー下部の「Export」ボタンをクリック
2. JSONファイルがダウンロードされる

### インポート
1. サイドバー下部の「Import」ボタンをクリック
2. 以前エクスポートしたJSONファイルを選択

### 自動バックアップ
`_json/` ディレクトリにバックアップファイルが保存されます。
形式: `mytasks_backup_YYYYMMDDHHMM.json`

## アクセシビリティ

- **ARIA属性**: モーダル、ナビゲーション、タスクリストに適切なロール設定
- **キーボード操作**: Escapeでモーダル閉じる、Enterで送信
- **フォーカス管理**: タスク追加後に入力欄にフォーカス
- **Reduced Motion**: アニメーション無効化設定に対応
- **High Contrast**: 高コントラストモードに対応
