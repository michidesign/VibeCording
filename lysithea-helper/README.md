# リシテア勤怠ヘルパー

Excelファイルからリシテアの勤怠入力画面に稼働データを自動入力するブラウザ拡張機能です。

## 🔒 セキュリティ

- **完全ローカル動作**: 外部サーバーとの通信は一切行いません
- Excelファイルはブラウザ内でのみ処理され、どこにも送信されません

## 📦 インストール方法（Edge / Chrome共通）

1. `edge://extensions/` または `chrome://extensions/` を開く
2. 「**開発者モード**」（または「デベロッパーモード」）をONにする
3. 「**展開して読み込み**」（または「パッケージ化されていない拡張機能を読み込む」）をクリック
4. `lysithea-helper` フォルダを選択

## 📋 使い方

1. リシテアの勤怠入力画面を開く
2. 拡張機能アイコンをクリック
3. 「Excelファイルを選択」でファイルを選択
4. プレビューでデータを確認
5. 「リシテアに入力」ボタンをクリック

## 📄 Excelファイル形式

| 列 | 項目 | 例 |
|---|------|---|
| A | 日付 | 2026/01/08 |
| B | JOBコード | 2162938001:名称 |
| C | 作業開始 | 0900 |
| D | 作業終了 | 1750 |
| E | 作業時間（任意） | 0850 |
| F | コメント | MTG参加 |

詳細は `EXCEL_TEMPLATE_README.md` を参照してください。

## 🎨 デザインシステム

本拡張機能のUIは**デジタル庁デザインシステム（DADS）**に準拠しています。

### カラーパレット

| 用途 | カラーコード |
|------|-------------|
| プライマリ | `#0071c1` |
| テキスト（主） | `#212529` |
| テキスト（副） | `#495057` |
| 背景（主） | `#ffffff` |
| 背景（副） | `#f8f9fa` |
| 成功 | `#28a745` |
| エラー | `#dc3545` |

### タイポグラフィ

- **フォント**: Noto Sans JP（Google Fonts）
- **本文サイズ**: 16px
- **行間**: 1.75

### アクセシビリティ

- **WCAG 2.2準拠**: コントラスト比 4.5:1 以上
- **タッチターゲット**: 最小48px
- **フォーカスインジケーター**: 3px outline（`#0071c1`）
- **8pxグリッド**: スペーシングシステム
