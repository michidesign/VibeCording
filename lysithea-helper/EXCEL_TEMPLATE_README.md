# リシテア勤怠ヘルパー - Excelテンプレート使用方法

## ファイル形式
Excel (.xlsx) または CSV 形式で保存してください。

## 列構成

| 列 | 項目名 | 入力形式 | 例 |
|---|--------|----------|---|
| A | JOBコード | 番号:名称 | 2162938001:【３Ｇ】ＮＴＴドコモｄカード／年間プロモーション業務 |
| B | 作業開始 | HHMM（4桁） | 0900 |
| C | 作業終了 | HHMM（4桁） | 1750 |
| D | 作業時間 | HHMM（4桁） | 0850 |
| E | コメント | 自由記述 | MTG参加 |

## Excelでのプルダウン設定手順

1. 別シート（例: "マスター"）を作成
2. A列にJOBコード一覧を貼り付け
3. データ入力シートのA列を選択
4. 「データ」→「データの入力規則」
5. 「リスト」を選択し、元の値にマスターシートのセル範囲を指定
