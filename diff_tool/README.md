# テキスト差分比較ツール

シンプルなテキスト差分比較（Diff）ツール。単一HTMLファイルで動作し、外部依存なしでローカル環境で利用可能。

## 機能

- **左右分割入力**: 元のテキストと変更後のテキストを並べて入力
- **差分表示**: 追加・削除・変更なしを色分けで視覚化
- **文字レベルハイライト**: 同一行内の変更箇所を強調表示
- **表示切替**: 左右表示（サイドバイサイド）/ 統合表示（インライン）
- **統計表示**: 追加・削除・変更なしの行数をカウント
- **ユーティリティ**: クリア、左右入れ替え
- **キーボードショートカット**: `Ctrl/Cmd + Enter` で比較実行
- **レスポンシブ対応**: モバイルでも利用可能
- **ダークモード対応**: システム設定に連動（Apple風・Google風）

## ファイル構成

```
diff_tool/
├── index.html        # デジタル庁デザインシステム版
├── index-apple.html  # Apple風デザイン版
├── index-google.html # Google Material Design版
└── README.md
```

## デザインバリエーション

| ファイル | デザイン | 特徴 |
|---------|---------|------|
| `index-dads.html` | デジタル庁（DADS） | Noto Sans JP、アクセシビリティ重視、青基調 |
| `index-apple.html` | Apple風 | ミニマル、ガラスモーフィズム、大胆な余白 |
| `index-google.html` | Material Design 3 | Roboto、エレベーション、セグメントボタン |

## 使い方

1. 任意のHTMLファイルをブラウザで開く
2. 左側に元のテキスト、右側に変更後のテキストを入力
3. 「比較する」ボタンをクリック（または `Ctrl/Cmd + Enter`）
4. 差分結果が下部に表示される

## 技術仕様

- **差分アルゴリズム**: LCS（最長共通部分列）ベース
- **依存ライブラリ**: なし（Vanilla JavaScript）
- **対応ブラウザ**: モダンブラウザ（Chrome, Firefox, Safari, Edge）
- **外部リソース**: Google Fonts（Noto Sans JP, Inter, Roboto, JetBrains Mono）
