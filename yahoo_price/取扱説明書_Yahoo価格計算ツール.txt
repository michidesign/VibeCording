================================================================================
  1. このツールについて
================================================================================

このツールは、東明工業株式会社のYahoo!ショッピング運営に特化した
「販売価格計算ツール」です。

商品の原価・送料・目標利益率を入力するだけで、Yahoo!ショッピングの
各種手数料・クーポン割引分をすべて加味した「推奨販売価格」を自動で算出します。

【主な機能】
  ・ 最大71商品を一括でExcelからアップロードして価格を算出
  ・ 現在の販売価格との比較・差額の自動表示
  ・ 個別商品の追加・管理
  ・ Yahoo!ショッピング手数料のカスタマイズ
  ・ 配送業者・サイズ別の送料テーブル管理
  ・ 計算結果のExcelファイル出力

【対応しているYahoo!手数料】
  ・ ストアポイント原資（最低1%）
  ・ キャンペーン原資（最低1.5%）
  ・ アフィリエイト報酬原資（最低1%）
  ・ アフィリエイト手数料（報酬原資の30%・自動計算）
  ・ 決済手数料（約3%）

※ 月額費用・初期費用・売上ロイヤルティはすべて無料のため含まれません。


================================================================================
  2. 起動方法
================================================================================

  1. 「yahoo_price_tool.html」ファイルをダブルクリックします。
  2. Google Chrome、Microsoft Edge、Safari など任意のWebブラウザで開きます。
  3. インターネット接続が必要です（SheetJSライブラリを読み込むため）。

【データの保存について】
  入力した商品データ・手数料設定・送料テーブルは、ブラウザの「ローカルストレージ」
  に自動保存されます。次回同じブラウザで開いた際、前回のデータが引き継がれます。

  ※ ブラウザのキャッシュ・履歴を削除すると保存データが消える場合があります。
  ※ 別のブラウザや別のPCで開いた場合、データは引き継がれません。

================================================================================
  4. 【Excel一括計算】タブの使い方
================================================================================

複数の商品をまとめて一度に計算したい場合に使用します。

------------------------------------------------------------------------
  4-1. テンプレートのダウンロード
------------------------------------------------------------------------

  ① 「① Excelテンプレートをダウンロード」カードの
     「⬇ テンプレートをダウンロード（.xlsx）」ボタンをクリックします。

  ② 「東明工業_価格計算テンプレート.xlsx」がダウンロードされます。

  ③ このテンプレートには以下があらかじめ入力されています。
       ・ 東明工業の全71商品の商品名
       ・ 各商品のカテゴリ
       ・ 現在の販売価格（税込・参考）
       ・ 商品コード（Yahoo!ストア管理用）

  【シート構成】
    「商品リスト」シート  ・・・ 商品一覧（ここに原価などを入力）
    「入力ガイド」シート  ・・・ 各列の説明と入力例

------------------------------------------------------------------------
  4-2. Excelへの入力方法
------------------------------------------------------------------------

「商品リスト」シートに以下の列があります。

  ┌──────────────────────────┬────────┬──────────────────────────────────┐
  │ 列名                       │ 必須   │ 説明                             │
  ├──────────────────────────┼────────┼──────────────────────────────────┤
  │ 商品名                     │ 必須   │ すでに入力済み（変更可）          │
  │ カテゴリ                   │ 任意   │ すでに入力済み（変更可）          │
  │ 現在の販売価格（税込・参考）│ 参照   │ 変更不要（計算には使用しない）    │
  │ 商品コード                 │ 参照   │ 変更不要                         │
  │ 原価（円）                 │ 必須   │ ★ 仕入れ価格を入力してください   │
  │ 目標利益率（%）            │ 必須   │ ★ 原価に対する利益率を入力       │
  │ 梱包サイズ                 │ 任意   │ 60/80/100/120/140/160/180/200    │
  │ 配送先地域                 │ 任意   │ 送料テーブルの地域名を入力        │
  │ クーポン割引率（%）        │ 任意   │ クーポン割引を上乗せする場合      │
  │ クーポン固定割引（円）     │ 任意   │ 固定額クーポンを上乗せする場合    │
  │ メモ                       │ 任意   │ 備考・管理用メモ                  │
  └──────────────────────────┴────────┴──────────────────────────────────┘

  ★ 「原価（円）」と「目標利益率（%）」のみ入力すれば計算できます。

  【梱包サイズの入力ルール】
    60 / 80 / 100 / 120 / 140 / 160 / 180 / 200 のいずれかの数値を入力します。
    （単位「サイズ」は不要。半角数字のみ）

  【配送先地域の入力ルール】
    以下の8地域名のいずれかを正確に入力します（コピー推奨）。
      北海道 / 東北 / 関東・信越 / 東海・北陸 / 近畿 / 中国・四国 / 九州 / 沖縄・離島

  【クーポン設定について】
    ・ クーポン割引率（%）：販売価格の○%引きクーポンを出す場合に入力
    ・ クーポン固定割引（円）：○円引きクーポンを出す場合に入力
    ・ どちらも使わない場合は「0」のままにしてください
    ・ 割引分のコストを自動で販売価格に上乗せして計算します

  【入力例】
    原価：3,000円　目標利益率：30%　梱包サイズ：120　配送先地域：関東・信越
    → 推奨販売価格が自動算出されます

------------------------------------------------------------------------
  4-3. Excelのアップロードと列マッピング
------------------------------------------------------------------------

  ① 入力済みのExcelを保存します。

  ② ツールの「② Excelをアップロード」カードを開きます。

  ③ 以下のいずれかの方法でファイルを読み込みます。
       ・ グレーのアップロードエリアをクリックしてファイルを選択
       ・ Excelファイルをアップロードエリアにドラッグ＆ドロップ

  ④ ファイルが読み込まれると「③ 列の対応を確認」カードが表示されます。

  ⑤ テンプレートをそのまま使っている場合、列の対応は自動で設定されます。
     表示内容を確認し、ずれている場合はプルダウンで修正してください。

  【列マッピング表示の見方】
    左側：ツールが必要としている項目名
    右側：読み込んだExcelの列名（プルダウンで選択）
    ※ 「（使用しない）」を選ぶとその項目は計算に使用されません

------------------------------------------------------------------------
  4-4. 計算の実行と結果の見方
------------------------------------------------------------------------

  ① 「③ 列の対応を確認」カードの「▶ 計算実行」ボタンをクリックします。

  ② 計算が完了すると、下部に結果が表示されます。

  【統計チップ（結果上部の概要）】
    ・ 総件数：読み込んだ商品の合計数
    ・ 計算成功：正常に計算できた商品数
    ・ エラー：計算できなかった商品数（原価未入力など）
    ・ 平均推奨価格（税抜）：成功した商品の平均推奨販売価格

  【結果表の列の説明】
    ┌──────────────────┬──────────────────────────────────────────────┐
    │ #                  │ 行番号                                       │
    │ 商品名             │ 商品名                                       │
    │ カテゴリ           │ 商品カテゴリ                                  │
    │ 原価               │ 入力した仕入れ価格                           │
    │ 利益率             │ 入力した目標利益率                           │
    │ 送料               │ テーブルから取得した送料（またはなし）        │
    │ 推奨価格（税抜）   │ ★ 算出された推奨販売価格（税抜き）           │
    │ 推奨価格（税込）   │ ★ 算出された推奨販売価格（税込み・10%）     │
    │ 現在の販売価格     │ テンプレートに記載の現在Yahoo!掲載価格       │
    │ 価格差（税込）     │ 推奨価格（税込）− 現在の販売価格             │
    │ 利益額             │ 1個あたりの利益額（円）                      │
    │ Yahoo!手数料       │ 各種Yahoo!手数料の合計額（円）               │
    │ メモ               │ 備考                                         │
    └──────────────────┴──────────────────────────────────────────────┘

  【価格差の色の意味】
    赤字（+○○○円）：推奨価格が現在の販売価格より高い → 値上げが必要な可能性
    緑字（−○○○円）：推奨価格が現在の販売価格より低い → 価格に余裕あり
    グレー（—）     ：現在の販売価格が未入力

  【エラー行（赤背景）について】
    「⚠ 商品名または原価が未入力」と表示された行は、原価または商品名が
    入力されていないため計算できていません。Excelを修正して再アップロードしてください。

------------------------------------------------------------------------
  4-5. 結果のExcel出力
------------------------------------------------------------------------

  ① 結果表の右上にある「⬆ Excelで出力」ボタンをクリックします。

  ② 「東明工業_価格計算結果_YYYYMMDD.xlsx」という名前で自動保存されます。
     （YYYYMMDDは実行日の日付）

  ③ 出力されるExcelには以下が含まれます。
       ・ すべての計算結果（推奨価格・利益額・Yahoo!手数料など）
       ・ 現在の販売価格との差額（テンプレート使用時）
       ・ エラーがあった行も「⚠」付きで記録

  5. 【個別商品管理】タブの使い方
================================================================================

1商品ずつ登録・管理・計算確認をしたい場合に使用します。

------------------------------------------------------------------------
  5-1. 商品の追加
------------------------------------------------------------------------

  ① 「＋ 商品を追加」ボタンをクリックします。

  ② 入力フォームが表示されるので以下を入力します。

  【基本情報】
    商品名（必須）     ：商品の名称を入力
    カテゴリ           ：プルダウンから選択（任意）
    原価（必須）       ：仕入れ価格（円）を入力
    目標利益率（必須） ：原価に対する利益率（%）を入力
                         例：原価1,000円、利益率30% → 利益300円

  【送料設定（3択）】
    テーブルから選択  ：梱包サイズと配送先地域を選ぶと送料が自動取得されます
    手動入力          ：送料を直接入力します
    送料なし          ：買い手負担の場合（計算に送料を含めません）

  【クーポン・セール設定】
    クーポン割引率（%）：クーポンの割引率を入力（不要な場合は0）
    クーポン固定割引額  ：固定額クーポンを入力（不要な場合は0）
    ※ 割引分は自動で販売価格に上乗せされます

  【メモ】
    管理用のメモを自由に入力できます

  ③ 「保存」ボタンをクリックすると商品一覧に追加されます。

------------------------------------------------------------------------
  5-2. 商品の編集・削除
------------------------------------------------------------------------

  【編集】
    商品カードの右上にある「編集」ボタンをクリックします。
    内容を変更し「保存」をクリックします。

  【削除】
    商品カードの右上にある「削除」ボタンをクリックします。
    確認ダイアログで「OK」をクリックすると削除されます。

------------------------------------------------------------------------
  5-3. 計算結果の確認
------------------------------------------------------------------------

  登録した商品カードに計算結果が表示されます。

  【左側：入力情報】
    原価・目標利益率・送料・クーポン設定が表示されます。

  【右側：計算結果】
    推奨販売価格（税抜） ：★ Yahoo!に掲載する価格の目安
    税込                 ：税込の推奨販売価格

  【費用内訳の確認】
    「▼ 費用内訳を表示」をクリックすると詳細が展開されます。
    原価・送料・利益額・各手数料の内訳が円単位で確認できます。


================================================================================
  6. 【手数料設定】タブの使い方
================================================================================

Yahoo!ショッピングの各種手数料率を設定します。
変更した場合は必ず「設定を保存」をクリックしてください。

------------------------------------------------------------------------
  設定項目の説明
------------------------------------------------------------------------

  【ストアポイント原資率】（最低1%）
    購入者に付与するYahoo!ポイントの原資。最低でも1%が必要です。
    → 例：2%に設定した場合、1,000円の売上につき20円分のポイントを負担

  【キャンペーン原資率】（最低1.5%）
    Yahoo!ショッピングのキャンペーンに使用される積立金。最低1.5%が必要です。

  【アフィリエイト報酬原資率】（最低1%）
    アフィリエイト経由の購入に対する報酬。最低1%が必要です。

  【アフィリエイト手数料】（自動計算・設定不要）
    アフィリエイト報酬原資に対して30%が自動的に加算されます。
    → 例：報酬原資1% → 手数料0.3%（合計1.3%）

  【決済手数料率】
    クレジットカード・PayPay等の決済時にかかる手数料。
    → 目安：約3%

  【最低手数料合計の確認】
    設定画面の下部に「最低手数料合計」が表示されます。
    各項目を最低値に設定した場合の合計は約6.8%です。

------------------------------------------------------------------------
  設定の変更方法
------------------------------------------------------------------------

  ① 各項目の数値を変更します（リアルタイムで合計が更新されます）。
  ② 「設定を保存」ボタンをクリックします。
  ③ 保存後、個別商品管理タブの計算結果も自動更新されます。

  ※ 設定はブラウザのローカルストレージに保存されます。

================================================================================
  8. 販売価格の計算方式（詳細）
================================================================================

ツールが販売価格を逆算する仕組みを説明します。

------------------------------------------------------------------------
  計算式
------------------------------------------------------------------------

  手数料率・割引率は「販売価格」に対してかかるため、
  以下の逆算式で推奨販売価格を算出しています。

  ◆ 「総控除率」の計算
    総控除率 = ストアポイント原資率 + キャンペーン原資率
               + アフィリエイト報酬原資率 + アフィリエイト手数料率
               + 決済手数料率 + クーポン割引率

  ◆ 「推奨販売価格（税抜）」の逆算
    推奨販売価格 =（原価 × (1 + 利益率) + 送料 + クーポン固定額）
                  ÷（1 − 総控除率）

  ◆ 「推奨販売価格（税込）」の計算
    推奨販売価格（税込）= 推奨販売価格（税抜）× 1.1

------------------------------------------------------------------------
  計算例
------------------------------------------------------------------------

  【入力値】
    原価       ：3,000円
    目標利益率 ：30%
    送料       ：1,650円（80サイズ・関東・信越）
    クーポン   ：なし

  【手数料設定（デフォルト）】
    ストアポイント原資率 ：1%
    キャンペーン原資率   ：1.5%
    アフィリエイト報酬   ：1%
    アフィリエイト手数料 ：0.3%（自動）
    決済手数料           ：3%
    合計                 ：6.8%

  【計算過程】
    ① 利益額    ：3,000 × 30% = 900円
    ② 分子      ：3,000 + 900 + 1,650 = 5,550円
    ③ 推奨価格  ：5,550 ÷（1 - 0.068）= 5,953円（税抜）
    ④ 税込価格  ：5,953 × 1.1 = 6,549円（税込）

  【費用内訳】

================================================================================
  9. よくある質問（FAQ）
================================================================================

  Q1. テンプレートに自社の商品がない場合は？
  A1. テンプレートの「商品リスト」シートに新しい行を追加して入力してください。
      商品名・原価・目標利益率の3列を入力すれば計算できます。

  ──────────────────────────────────────────────────────────────

  Q2. アップロードしたExcelの列の順番が違う場合は？
  A2. ③の「列の対応を確認」画面でプルダウンから正しい列を選び直してください。
      ヘッダー行（1行目）の列名が合っていれば自動的に対応します。

  ──────────────────────────────────────────────────────────────

  Q3. エラー行が表示される場合は？
  A3. 主な原因は以下のとおりです。
      ・「原価（円）」列が空欄になっている
      ・「商品名」列が空欄になっている
      ・手数料率の合計が100%以上になっている（設定タブを確認）
      Excelを修正後、再アップロードして計算を実行してください。

  ──────────────────────────────────────────────────────────────

  Q4. 送料が「—」と表示される場合は？
  A4. 梱包サイズまたは配送先地域が未入力か、正しく入力されていません。
      サイズは「60」「80」などの数値のみ、地域は正確な名称を入力してください。
      送料がかからない場合は意図的に空欄でもかまいません。

  ──────────────────────────────────────────────────────────────

  Q5. 価格差が赤字（+○○○円）になっている商品は？
  A5. 現在の販売価格が「推奨価格より低い」ことを意味します。
      現在の価格では手数料・原価・利益を賄えていない可能性があります。
      価格の見直しをご検討ください。

  ──────────────────────────────────────────────────────────────

  Q6. 登録した商品データが消えた場合は？
  A6. ブラウザのキャッシュや履歴を削除するとデータが消えることがあります。
      重要なデータは「Excelで出力」機能を使って定期的にバックアップしてください。

  ──────────────────────────────────────────────────────────────

  Q7. 手数料率を変更した場合、過去の計算結果は変わりますか？
  A7. 「個別商品管理」タブの表示はリアルタイムで再計算されます。
      Excel出力済みのファイルは変わりません。
      一括計算タブは「計算実行」ボタンを再度押すと最新の設定で再計算されます。

  ──────────────────────────────────────────────────────────────

  Q8. Yahoo!ショッピングの手数料が変わった場合は？
  A8. 「手数料設定」タブで各率を最新の値に更新し「設定を保存」をクリックしてください。
      なお、2026年9月以降に料金体系の変更が予定されています。
      変更があった場合は手数料設定タブの値を更新してください。

  ──────────────────────────────────────────────────────────────

  Q9. クーポンを設定したくない場合は？
  A9. クーポン割引率を「0」、クーポン固定割引額も「0」のままにしてください。
      計算結果に影響しません。

  ──────────────────────────────────────────────────────────────

  Q10. スマートフォンから使えますか？
  A10. 対応していますが、表の横幅が広いため、タブレットやPCでの使用を推奨します。
