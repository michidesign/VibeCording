# MD Converter - マークダウン変換ツール

マークダウン形式と一般テキスト形式を双方向にリアルタイム変換するWebツールです。

## 概要

マークダウン記法を読みやすい一般テキストに変換できます。逆変換も可能なため、一般テキストからマークダウンへの変換も行えます。

## ファイル一覧

| ファイル | デザインシステム | 説明 |
|---------|----------------|------|
| `index-dads.html` | Digital Agency Design System | 行政機関向けデザイン、Noto Sans JP |
| `index_apple.html` | Apple Design | ミニマル、ガラスモーフィズム |
| `index_google.html` | Material Design 3 | Google風、エレベーション表現 |

※ すべてのファイルは同一機能で、デザインのみ異なります。

## 主な機能

### 双方向リアルタイム変換
- 左パネル（Markdown）と右パネル（一般テキスト）で構成
- 編集中のパネルを自動検知し、反対側にリアルタイムで変換結果を表示
- 変換方向はインジケーターで確認可能

### カスタマイズ可能な変換ルール
- 設定画面（⚙️ボタン）から変換ルールを自由に編集
- ルールの追加・削除・有効/無効切り替えが可能
- 設定はブラウザのlocalStorageに自動保存

### その他の機能
- ダークモード対応（🌙ボタンで切り替え）
- ワンクリックコピー機能
- レスポンシブデザイン（モバイル対応）

## デフォルト変換ルール

| Markdown | 一般テキスト | 説明 |
|----------|-------------|------|
| `## ` | `■ ` | 見出しレベル2 |
| `### ` | `● ` | 見出しレベル3 |
| `#### ` | `○ ` | 見出しレベル4 |
| `- [x] ` | `✓ ` | 完了チェックボックス |
| `- [ ] ` | `□ ` | 未完了チェックボックス |
| `- ` | `・` | 箇条書き |
| `* ` | `・` | 箇条書き（別記法） |
| `> ` | `│ ` | 引用 |
| `1. ` 〜 `9. ` | `① ` 〜 `⑨ ` | 番号付きリスト |
| `` `code` `` | `「code」` | インラインコード |
| `**text**` | `【text】` | 太字 |

## 使い方

1. HTMLファイルをブラウザで開く
2. 左パネルにMarkdownを入力 → 右パネルに変換結果が表示
3. 右パネルに一般テキストを入力 → 左パネルにMarkdownが表示
4. 変換結果をコピーボタンでクリップボードにコピー

### 変換ルールのカスタマイズ

1. ⚙️ボタンをクリックして設定画面を開く
2. 既存ルールの編集：テーブル内の入力欄を直接編集
3. 新規ルール追加：フォームに入力して「追加」ボタン
4. ルール削除：🗑ボタンをクリック
5. 初期設定に戻す：「初期設定に戻す」ボタン

## 技術仕様

- **構成**: 単一HTMLファイル（外部依存なし）
- **動作環境**: モダンブラウザ（Chrome, Firefox, Safari, Edge）
- **データ保存**: localStorage
  - 変換ルール: `md_converter_rules_v1`
  - テーマ設定: `md_converter_theme`
